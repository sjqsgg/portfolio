# 第三轮：相机区域与洞洞板视角

## 用户确认的范围

修复跨页转场只显示四分之一；恢复 Photography 的 Portraits 和 Selected moments 两个行标题，其余保持；相机区任何物件先进入 01c，再点击相机进入摄影页；降低 01c；增加四周留空的洞洞板近景；移除常驻场景提示。洞洞板内容另行讨论。

## 本轮修改

1. **转场覆盖**：将 `clip-path` 的绝对像素路径替换为百分比 `shape()` 曲线。浏览器不支持 `shape()` 时使用 64 段百分比多边形曲线。形状按快照本身的大小解析，避免快照与页面像素坐标不同；保留 2.15 秒节奏。
2. **画廊标题**：只恢复两排 `h2`。数量、暂停按钮和底部说明不恢复，悬停和移动行为保持。
3. **相机区入口**：实际射线命中两台相机、独立镜头、杯子、书／支架、音响架、相机桌面及后板时，若尚未在 photo 视角，先靠近。近景中只有两台相机机身直接进入 Photography；书的原有留言功能仍可用。
4. **01c 构图**：桌面相机位置 `[.28, 1.10, .78]`、目标 `[.28, .84, -.66]`、视角 34°，俯角约 10.2°。删除旧的 `[-210,-100]` 投影偏移；手机另向左居中以完整容纳两台相机。01b 的位置、目标和视角不变。
5. **洞洞板**：点击板面或耳机打开独立原生对话框，居中正面观察实际模型的洞洞板及其现有挂件。四周保持间隙，点击外侧、× 或 Esc 关闭；保留原来的工作台视角。没有增加新挂件、说明内容或新栏目。
6. **场景提示**：移除 01a/b/c 底部导航、常驻物件文字、引导文字和文字返回提示。保留右下角 Revert、主导航及已确认的悬停胶囊。屏幕阅读器与键盘仍能操作物件，键盘聚焦时才显示轮廓。
7. **回退画面**：更新与新镜头一致的静态预览及对应透明点击区域，供省流量、减少动态效果及 WebGL 不可用时使用。

## 验证方式

`tests/scene-round.spec.js` 新增 6 项测试：1/2/3 倍像素比例下检查转场四个区域的实际截图颜色（含页面 CSS 缩放、百分比多边形回退）；逐个点击相机区实际物件；两台相机二次点击；洞洞板板面入口、外侧关闭、Esc、焦点恢复和手机边距。

`docs/qa/scene-round/` 保存桌面与手机模型、洞洞板、转场截图。原有文档、画廊和移动端测试按新的键盘物件入口更新。

说明：无头 Chrome 的 Retina 复现未重现用户截图中的四分之一裁切；新的百分比实现以覆盖截图测试验证，并消除了绝对像素路径的缩放依赖。不将 CSS 缩放测试等同于所有实体设备和浏览器缩放组合。
